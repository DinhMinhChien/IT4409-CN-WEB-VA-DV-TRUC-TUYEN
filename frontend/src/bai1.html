Danh sach loi trong file news_wrong.html

  • Dòng khai báo DOCTYPE: File news_wrong.html sử dụng <!DOCTYPE HTML5>, trong khi file chuẩn news.html là <!DOCTYPE html>.
  • Thẻ meta charset: File sai định dạng bộ mã thành <meta charset="UTF-88">, thay vì <meta charset="UTF-8">.
  • Thẻ title: Thẻ <title>News - Blakletterpress Website Template trong file sai bị thiếu thẻ đóng </title> ở cuối dòng.
  • Thẻ body: File news_wrong.html viết sai thẻ mở thành <boby>, từ đúng phải là <body>.
  • Thuộc tính alt của ảnh logo: Thẻ <img src="images/logo.png"> bị thiếu thuộc tính alt="LOGO" so với bản gốc.
  • Thẻ input submit: Thẻ <input type="submit" value="Search" class="btn" trong form tìm kiếm của file sai bị thiếu dấu ngoặc nhọn đóng > ở cuối.
  • Thẻ đóng của header: File sai dùng thẻ </section> để đóng khu vực header, trong khi cấu trúc đúng đang sử dụng </div>.
  • Dấu ngoặc kép trong thuộc tính class: Ở bài viết đầu tiên, file sai bị lỗi dấu nháy đơn kết hợp nháy kép thành class="time', bản chuẩn là class="time".
  • Thẻ tiêu đề bài viết: Ở bài viết đầu tiên, file sai dùng thẻ <h7> (không hợp lệ trong HTML), thay vì dùng thẻ <h3>.
  • Thẻ đóng đoạn văn: Ở phần tin tức thứ hai, file news_wrong.html thiếu thẻ đóng </p> ở cuối đoạn văn bản miêu tả.
  • Thẻ đóng liên kết (anchor tag): Ở phần tin tức thứ ba, file sai thiếu thẻ đóng </a> cho phần <a href="news.html" class="more">Read more >>.
  • Thẻ đóng danh sách: File sai dùng thẻ </ol> để đóng danh sách, trong khi thẻ mở ban đầu là <ul id="list"> nên thẻ đóng đúng phải là </ul>.
